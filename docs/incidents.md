# Журнал типовых инцидентов

| Инцидент | Признак | Где смотреть |
|---|---|---|
| Неиспользуемая переменная | Красный `pylint` в PR | Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал `deploy-pages` |
| Битая ссылка | Строгая сборка MkDocs падает | Build documentation |
